# PygameCERTO
Jogo pygame DeSoft

AUTORES:
Cristiana Pacces, Julie Yoshihiro

DESCRIÇÃO DO PROJETO:
O projeto é um jogo de delivery que se chama "Entregando". O personagem principal é um entregador de bicicleta que precisa atravessar uma cidade movimentada desviando de diversos obstáculos urbanos. O objetivo do jogador é sobreviver o maior tempo possível, acumulando pontos enquanto realiza entregas pela cidade.

ARQUIVO PARA EXCECUTAR: jogo.py

IA: 
Utilizamos IA para corrigir erros ao longo do processo de criação do jogo.
